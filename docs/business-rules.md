# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。

## 幂等（请求标识）

- 调用方可在受理订单、登记收款时携带 `Idempotency-Key`；作用域为（租户, 请求标识），跨租户同名标识互不影响。
- 同一（租户, 请求标识）视为同一次业务请求：首次请求执行业务；之后无论重复提交多少次（含网络重试、并发提交），都返回首次的状态码与响应体，不产生新的受理记录、不重复累加收款、不改变已有金额与状态。
- 同一请求标识被用于不同业务内容（金额、币种、收款金额不同，或用于不同业务端点）时必须拒绝（409），拒绝不得写入或改动任何数据；冲突结论持久有效。
- 并发提交同一请求标识时，只允许一次请求真正产生业务效果（业务表与请求标识登记在同一事务内提交）。
- 幂等结论持久化：服务重启后，已处理标识仍按重复请求重放，曾被拒绝的冲突请求结论保持一致。
- 不携带请求标识的请求按原规则处理：重复受理 409、超额收款 409、跨租户读取 404。
