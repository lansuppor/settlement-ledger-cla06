# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 冲正（退款）减少已收金额：单次冲正不得超过当前已收金额，超出拒绝且不留痕；冲正后已收低于订单金额则回到未结清，等于订单金额则结清。
- 冲正标识由调用方生成，作用域为（租户, 订单, 冲正标识），与订单标识是不同层次身份，不能互相替代；同标识重复请求幂等回放首次结果。
- 收款与冲正统一记入订单流水，按发生顺序排列；已收金额恒等于生效收款之和减去生效冲正之和，任意时刻不小于零、不大于订单金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在；冲正的跨租户请求同为 404 且不留痕。
- 金额以最小货币单位的正整数表示，不使用浮点数。
