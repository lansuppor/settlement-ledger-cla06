# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取或写操作一律按“不存在”处理（404），不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 冲正（退款）针对已收金额：
  - 冲正标识由调用方生成，作用域为（租户，订单），与订单标识是不同层次身份，不可互相替代；不同（租户，订单）下同一标识互不影响。
  - 同一（租户，订单，冲正标识）重复请求幂等：只首次生效，重试返回首次结果与首次生效时间，HTTP 200。
  - 单次冲正金额不得超过当前已收金额，超出 409 且事务整体回滚、不留痕迹；订单不存在 404；参数不合法 400。
  - 同一冲正标识携带不同金额重试，按冲突（409）处理且数据不变。
  - 已收低于订单金额回到未结清（`accepted`），等于时结清（`settled`）。
- 账务守恒：`paid_cents` 恒等于生效收款之和（无凭据收款 + 未撤销的凭据收款）− 生效冲正之和；登记收款、冲正与凭据操作并发时由单写事务串行化，任意时刻满足 `0 ≤ paid_cents ≤ amount_cents`。

## 收款凭据

- 凭据标识由调用方生成，为非空字符串；作用域为（租户，订单），与订单标识、冲正标识是不同层次身份，互不替代；不同（租户，订单）下同一标识互不影响。同一（租户，订单）下活凭据标识不得重复，重复登记 409 且不留痕。
- 登记收款带凭据标识时，收款进入待核销（`pending`）：立即计入 `paid_cents` 与流水（凭据条目带标识、状态与余额快照），可继续用于收款与冲正的上限计算；但只要存在待核销收款，订单不因收款而结清。
- 核销确认（confirm）：待核销 → 已核销（`confirmed`），余额不变，订单按现有规则重新判定结清与否。重复确认返回首次结果（含首次的 `paid_cents`、订单状态与时间快照）、HTTP 200、幂等标记 true，不重复留痕、不改余额；非待核销凭据确认 409。
- 撤销（revoke）：整笔移除待核销收款，`paid_cents` 减少该金额，补一条撤销流水（含凭据标识与余额快照），只影响该笔；活凭据行删除并在只追加的事件表留痕，撤销后同名凭据可再次登记。已核销/已冲正凭据撤销 409 且数据不变；待核销资金若已被其他冲正占用、整笔撤销会使余额为负时同样 409 且数据不变；重复撤销返回首次结果、HTTP 200、幂等标记 true。
- 以凭据冲正（receipt refund）：沿用普通冲正的幂等、上限、原子性与 400/404/409 规则；冲正金额必须与凭据金额一致，只有已核销凭据可冲正，待核销或已撤销凭据直接冲正 409 且数据不变，冲正后凭据标记已冲正（`refunded`）。同一冲正标识重试幂等回放首次结果；同一冲正标识换金额或换凭据 409。
- 凭据不存在或跨租户，三个凭据操作一律 404（不泄漏对象是否存在）；参数不合法 400。所有凭据操作要么整体生效（余额、状态与流水同时改变），要么完全不生效。
