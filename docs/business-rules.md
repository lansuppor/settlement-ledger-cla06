# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取或写操作一律按“不存在”处理（404），不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 冲正（退款）针对已收金额：
  - 冲正标识由调用方生成，作用域为（租户，订单），与订单标识是不同层次身份，不可互相替代；不同（租户，订单）下同一标识互不影响。
  - 同一（租户，订单，冲正标识）重复请求幂等：只首次生效，重试返回首次结果与首次生效时间，HTTP 200。
  - 单次冲正金额不得超过当前已收金额，超出 409 且事务整体回滚、不留痕迹；订单不存在 404；参数不合法 400。
  - 同一冲正标识携带不同金额重试，按冲突（409）处理且数据不变。
  - 已收低于订单金额回到未结清（`accepted`），等于时结清（`settled`）。
- 账务守恒：`paid_cents` 恒等于生效收款之和 − 生效冲正之和；登记收款与冲正并发时由单写事务串行化，任意时刻满足 `0 ≤ paid_cents ≤ amount_cents`。
